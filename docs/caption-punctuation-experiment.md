# 通用断句续测：缩写、独立标点与漏译检查

本轮仍是隔离实验，**没有达到 95% 发布门槛，没有替换生产缓存、默认识别管线或 APK**。版本号不变。前一轮的 6 个新视频现已用于调试，因此本轮将它们标为开发/回归集，不再冒充未见测试集。

## 代码修正

- 称谓缩写（Mr./Mrs./Ms./Dr./Prof./Rev./Hon.）及姓名首字母不直接视为句末；不把所有带点单词都列入白名单，U.S. 仍可能结束一句话。长时间间隔仍保留安全切分和待审标记。
- spaCy 把 `it.` 分成代词和句点时，句点不再覆盖代词本身的词性/依存关系。区分宾语结束语句与主语连接助动词：`...this. We're...` 不应因为 PRON/AUX 相邻而合并，`we are` 仍受到保护。
- 增加独立英文标点模型的实验入口。模型只建议边界，使用带左右上下文的词窗口、首子词标签和严格 token 上限，不截断超限输入、不修改 ASR 原词及其时间。原始识别词与用于语法分析的补标点视图分开保存。
- 修复“英文缺少句末点 → 中文译到逗号结束仍被接受”的检查漏洞；重试时可只补句末点，仍失败则英文回退，不把不完整中文标为成功。此检查不是语义完整性证明，中文中间漏掉信息依然可能通过。

独立标点参考 [rpunct 官方实现](https://github.com/Felflare/rpunct) 与 [模型说明](https://huggingface.co/felflare/bert-restore-punctuation)。模型是评论语料训练的 BERT，并非口语/多人说话专用模型，不能当作说话人分离器。下载固定 revision `954108a105ef1f89f08b71c25d6e33bb89cde724`，核验权重 SHA-256；只加载本地权重、禁止远程代码，不安装原项目的旧推理框架，不下载训练状态。约 436 MB 权重仅在被忽略的实验目录中。

## 不能只看句子更短：独立句界核对

新审计工具对出版方完整英文字幕中的句末位置计算精确句界 precision/recall/F1。替换、插入、无法对齐的边界不会静默排除：没有被预测命中的参考句界计漏切，额外/无法对齐的预测句界计多切。该指标是**出版字幕句界一致性**，不是人工听审准确率；出版方可能省略口头语，也可能用冒号代替句号。

| 完整 TED 视频 | 前轮 r7 F1 | 本轮仅追加标点边界 r1 | 本轮重分析与语法修正 r4 |
| --- | ---: | ---: | ---: |
| Try something new for 30 days | 87.32% | 87.32% | 87.32% |
| How to start a movement | 70.97% | 72.46% | 78.26% |
| Every kid needs a champion | 84.26% | 84.42% | 83.67% |

`movement` 有改善，但 `champion` 有退步，因此**不能宣布新模型全面优于旧方案，不能直接升为默认**。r2、r3 中间结果也保留，不仅保留最佳一轮。

## 具体改善与剩余失败

- `The Interview` 中 `Ms. Weaver` 已保持在同一学习句中；不按具体人名做替换。
- `movement` 中原 63 词长单元在第一轮模型建议下拆为 4 段，找回了一些之前漏译的分句；后续语法修正把 `first` 放回下一句开头，而非附在 `...lessons from it` 后。
- 即使分短，NLLB 仍可能遗漏短句的修饰语；例如译文在逗号处提前停止。新增检测能触发重试/回退，但不能证明所有生成中文完整。
- 本轮真实重试已补回 `with a crucial role` 及 `and show others how to follow` 对应的中文内容；另一个较长单元重试仍失败，保留英文回退。这些是具体改善案例，不替代全片中文人工审核。
- 多人对话仍有错误合句，当前文本模型没有声学说话人身份，不能把文本句末预测说成已实现说话人分离。
- 计数重复、识别幻觉、低置信度时间边界仍沿用原始待审证据，本轮不靠删除词/改动时间提高分句分数。

## 复现入口

1. `tools/utilities/download_punctuation_experiment_model.py`：隔离下载并核验固定权重。
2. `tools/validation/run_punctuation_experiment.py`：对完整对齐词生成独立标点证据。
3. `tools/validation/replay_punctuation_evidence.py`：保存特征上的追加证据对照，不重跑 ASR。
4. `tools/validation/run_cohort_learning_experiment.py --punctuation-root ...`：补标点分析视图 → SaT/spaCy 重分析 → 原词分句；翻译阶段单独运行。
5. `tools/validation/audit_publisher_boundaries.py`：完整出版字幕句界核对，包含误切和漏切。
6. `tools/validation/audit_pipeline_integrity.py`：全部来源词、顺序、时间范围和翻译输入守恒，**不是准确率验收**。
7. `tools/validation/run_reserved_punctuation_holdout.py`：冻结配置后对新备用片执行完整识别、对齐、标点、分句、翻译、OCR 和审计。

所有原视频、完整出版方转录、原始 OCR 和模型权重均不进入 Git。正式发布仍需未参与调参的多个完整视频，在逐句文本、句界、时间与中文语义四方面分别通过独立审核。

最终电脑端 **229 项单元测试通过**，覆盖缩写、句点词性覆盖、宾语/主语区别、上下文窗口完整覆盖、未启用实验的默认行为、参考边界漏切/多切/重复计数以及未加句点原文的漏译检测。编译与差异空白检查通过。机器可读结果：[caption-punctuation-results.json](caption-punctuation-results.json)。本轮没有向 GitHub main 推送未达标实验。
