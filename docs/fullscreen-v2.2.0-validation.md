# v2.2.0 全屏播放验证记录

## 全屏拖动与连续播放修复（2026-10-09）

版本保持 `2.2.0 / 29`，沿用原调试签名。前一安装包保留在提交 `3318af3`，其他旧版本 APK 不变。

### 根因与行为

- 原字幕区域固定扣除顶部 60dp、底部 92～140dp，即使控制栏隐藏也不能拖到边缘。现在只避开实际刘海、当前可见系统栏和 4dp 边距，字幕整体保持在屏幕内；长句横向可移动距离自然小于短句。拖动时隐藏控制栏，显隐设置不再改变可移动区域。新用户/复位默认位置相应调整，已有位置和锁定状态仍保留。
- 原全屏播放和双击保留单句状态，句尾监视器因此仍停止/循环。现在所有播放入口共用连续播放逻辑：单句预览中或结束后操作，从当前位置连续播放、不回句首；已经连续播放时再次操作则暂停。文字/图标与此一致。
- 上/下一句单独触发时只播放目标句一次，即使此前开启循环。主动点击循环或复读仍可进行单句练习，不删除用户的循环偏好。
- 增加播放器准备状态保护，避免定时进度读取和播放操作在异步准备完成前进入无效状态；测试也等待准备完成后再读取时长。

### 验证范围

独立 Android 16 / API 36.1 模拟器，720×1600 / density 280；真实 12:46 横屏视频及 12 秒竖屏几何视频。字幕为可控的界面测试样例，不是字幕识别质量评测，也没有声称完整观看视频。

原 17 项回归增加五项：触摸拖到四个安全边角、打开设置位置不变；循环偏好下导航仍仅播一次；句尾后点播放不回退；上一句播放途中点播放跨句尾；下一句播放途中双击跨句尾并可再次双击暂停。保留字幕开关、翻译开关、锁定/字号/复位、查词、横竖屏切换、后台恢复和字幕空隙导航检查。

调试时没有计入通过的轮次：播放器准备状态竞争；模拟器关闭导致测试中断；重新启动后的 Android 首次全屏提示遮挡手势；旧坐标/触摸时序导致学习页双击回归失败。准备状态保护、提示确认及测试坐标更新后重新进行验收，不把局部成功冒充完整通过。

## 控制栏修复复验（versionCode 29，版本名称仍为 2.2.0）

### 修复内容

- 原先将隐藏状态栏的 insets 应用于整个 overlay，导致标题 / 控制栏背景整体内缩。本次背景延伸到屏幕边缘，控件内部只避开实际刘海和可见系统栏，进入全屏允许画面延伸到短边刘海区域；没有去掉刘海保护。
- 全屏增加上句 / 下句，复用学习页 `moveSelection` 和时间轴导航，不复制一套选句规则。
- 学习页改为单击显隐控制栏、双击播放 / 暂停；进度、时间、播放和全屏入口在视频内。控制栏默认隐藏，播放时 3 秒自动隐藏，拖动进度时暂停隐藏计时。退出全屏后恢复隐藏。
- 单双击由同一个 GestureDetector 处理，不再让单击和双击都切换播放；保留单句 / 循环模式。

## 重复执行

使用独立 Android 13+ 模拟器（测试会改变测试 App 的视频、字幕设置和单词本），配置 JDK 17、Android SDK，并准备横屏真实视频和竖屏视频：

```powershell
powershell -ExecutionPolicy Bypass -File tools/tests/integration/test_fullscreen_v2_2_0.ps1 `
  -Serial emulator-5556 `
  -VideoPath 'C:\media\landscape.mp4' `
  -PortraitVideoPath 'C:\media\portrait.mp4'
```

横屏素材需长于 60 秒，竖屏素材需高大于宽。脚本固定模拟器测试文件名，不改源视频。使用已构建 APK 时可加 `-SkipBuild`。测试源：`app/src/androidTest/java/com/codex/videolearnenglish/FullscreenInstrumentation.kt`；字幕定位单元测试：`FullscreenSubtitlePositionTest.kt`。

脚本遇到断言失败或测试进程崩溃会报告失败，截图拉取到 Git 忽略的 `tools/runtime/v2.2.0/fullscreen-validation/`。图像用于本地复查，不把用户的视频素材提交到公共仓库。
