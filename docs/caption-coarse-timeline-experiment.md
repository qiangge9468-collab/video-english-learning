# 全片粗时间轴与声学分块实验（未发布）

日期：2026-10-07。沿用现有手机端/电脑端版本号，只在隔离工作区实验。

## 为什么不能继续只修断句

上一轮发现缓存中的完整旁白提前约 38 秒，局部强制对齐仍可能输出看似正常的词时间。旧缓存没有保存最早 ASR 输出，因此不能仅凭最终缓存断定是历史识别窗口、VAD 时间还原还是历史对齐首先引入了偏移。可以确认的是：重新给错误旧段做小幅局部对齐，不能解决这种大幅错位。

本轮保留两个通用对照，不使用片名、预期台词、问题时刻或 OCR 作为识别提示：

1. **固定时间窗口**：每 20 秒核心区带前后各 4 秒音频上下文，不压缩静音；按原始采样位置还原时间。窗口边界所有权和零时长词仍需要专门检查，不能因为不存在全片累计偏移就宣称识别正确。
2. **完整 WhisperX ASR 路线**：使用 WhisperX 本身的无时间戳文本解码，再声学对齐，不只是用 WhisperX 对旧字幕二次对齐。VAD 使用已安装的 faster-whisper 离线 Silero ONNX；最多 20 秒、最长跨 1 秒停顿的原音频窗口，不拼接压缩语音。保留数字、不注入固定主题词。该候选在对齐前不伪造逐词时间。

固定窗口第一部音频导出时遇到 NumPy 布尔值 JSON 序列化错误，原始所有窗口日志已保留；修改输出为原生数值类型后，从原日志重新导出 Switzerland，不冒称重新运行了该片模型。其他影片继续实际全片识别。复用路径与原始日志 SHA-256 写入输出报告，先前失败目录不覆盖。

## 对齐回退修正

`source-local-fallback-v2` 将缺失/异常词的回退限制在对应词上。未能对齐的金额不再使同一句的所有有效词都退回均匀估计。没有可靠原时间的未对齐词，仅在相邻可靠锚点间估计并明确标记 `estimated_review_required`；这个时间仍未校验，不能用于证明达到 0.5 秒误差要求。低 CTC 分数只影响相应词的告警，不当作识别概率。实验缓存指纹包含新策略号。

这里并非断言当前 WhisperX 无法处理所有数字。核对本地 3.8.6 的 `alignment.py` 及上游 [3.5.2 回移修复说明](https://github.com/m-bain/whisperX/releases/tag/v3.5.2)，当前实现已有 wildcard emission，可为字典外字符生成候选时间；较旧 README 的数字限制不能直接当作当前版本行为。候选仍可能缺失、过长或落在错误音频上，局部保留/回退逻辑针对这些实际失败，不把 wildcard 的高分当作数字读法已被验证。

## WhisperX 完整路线结果

`.validation/whisperx-asr-r1/` 为四部完整音频的实际 CUDA 识别；`.validation/whisperx-pipeline-r1/` 接着处理同一批输出，完成对齐、SaT/spaCy 分句及 NLLB 通用模式整句翻译。原始 ASR 没有伪造逐词时间，由对齐阶段生成或明确估计。源码/输入指纹和各阶段退出码均保留，ASR 约 1,173 秒，后三阶段约 259 / 160 / 554 秒。

| 音频 | ASR / 保留词数 | 学习句 | 显示块 | 英文回退 | 未校对 OCR 候选词匹配率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Switzerland | 1,697 | 174 | 195 | 6 | 87.04% |
| Rinjani | 3,812 | 376 | 408 | 7 | 88.61% |
| Bangladesh | 4,136 | 440 | 463 | 11 | 80.54% |
| AIRFLARE | 2,855 | 240 | 296 | 2 | 未知 |

1,230 条学习句中，1,130 条生成译文未审核、26 条英文回退、74 条确定性数字转换。此轮确实完成整个流程，但**没有稳定优于完整无 VAD/固定窗口对照**，不作为默认方案。新的大段 ASR 窗口内，CTC 仍会把部分文字对齐到更早的不同声音；高 CTC 分数并不能证明位置正确。

全片输出还暴露出约 45 秒间隔两边被合成一个学习句的情况：语法保护把句末助动词当成未完句，而之前的学习句模式只把已单独标注的声学停顿当作硬边界。因此后续增加 `learning_max_join_gap_seconds=4` 的学习单元安全上限，跨长词间隔时拆开并给两侧 `boundary_review_required` 告警。这个限制是播放/翻译保护，**不将词时间间隔冒充经听音确认的静音**，也不删词。普通停顿的主语/助动词仍保护为一组。

`source-drift-guard-v3` 进一步检查连续至少 3 个可用 ASR 时间锚点：若 CTC 同方向移动超过 1.5 秒，不只按其分数接受，而是保留原识别时间、标记分歧待审。旧 WhisperX 时间和零时长估计不能作为独立锚点；原 ASR 时间也不是最终真值。缓存策略号同步变更，避免复用不同策略的结果。

`audit_ocr_timeline.py` 将完整字幕文本中的唯一精确短语与全片 OCR 候选连接，定位超过原局部搜索范围的大幅偏移。重复/过短/无匹配字幕全部保留，不自动纠正；某句话在音频重复但漏识别一次，也可能形成假唯一匹配，必须检查上下文。显示时刻不等于发音时刻，报告不输出“同步准确率”。

## 第二种本地识别模型

为避免只靠 Whisper 自我对照，新增独立的 [NVIDIA Parakeet-TDT 0.6B v2](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v2) 英文识别候选，使用 [sherpa-onnx 官方适配方案](https://k2-fsa.github.io/sherpa/onnx/pretrained_models/offline-transducer/nemo-transducer-models.html)。这是模型对照，不是人工真值，也不是已选定的新默认依赖。

测试依赖安装到 Git 忽略的 `.validation-deps/parakeet/`，没有修改生产 Conda 环境。模型来自维护者发布的 `csukuangfj/sherpa-onnx-nemo-parakeet-tdt-0.6b-v2-int8`，固定提交 `1ab9323565ddb038682214b292f588070a538ce2`，三个 ONNX 文件校验发布 SHA-256；模型许可证 CC-BY-4.0，sherpa-onnx 为 Apache-2.0。仅下载模型到本机，音频不上传外部服务。

初次整片运行在货币格式导出处失败：显示文本将 `extra $2,000` 格式化为 `extra$2,000`，BPE 原词序仍保留空格。修复只允许空白差异，词内容有任何变化仍报错；时间映射采用原 BPE 边界，不凭显示字符串猜时间。失败目录保留，续轮另用新目录完整重跑；短样本接口测试不计入全片验证。

四部完整音频的第二轮均已完成，CPU 共约 939 秒（`.validation/parakeet-asr-r2`）。输出词数分别为 1,708 / 3,889 / 4,048 / 2,839；前三片未校对 OCR 候选词匹配率为 85.37% / 88.80% / 77.77%，AIRFLARE 无连续口播硬字幕参考。这些结果未全面优于 Whisper，不替换主识别模型。Parakeet 仍有漏句和词汇错误，不能因为采用不同模型就充当真值；此轮仅完成 ASR 和诊断，没有冒称完成 Parakeet 的分句翻译管线。

## 短句时间保护与全片词序检查

`source-drift-guard-v3` 的“连续至少 3 个锚点”仍会漏掉只有一两个可靠时间词的短句。后续 `bounded-source-disagreement-v4` 改为逐个独立 ASR 锚点检查 1.5 秒以上的时间分歧，保留原时间并待审。普通小幅精调仍可接受；原 ASR 错误时，这个回退也可能错误，绝不当成时间已校准。

另一个真实回归是混用 CTC 和原时间后改变词序。AIRFLARE 约 18 分钟的一处输出从原来的 `so really push your` 变成了 `so push really your`。现在只向发生交叉的相邻 CTC 词传播回退，不按错误时间排序来掩盖句内词序问题；原始候选、重试和拒绝原因完整保存，其他有效词时间不整段回退。

`.validation/windowed-pipeline-r5` 使用同一批完整固定窗口 ASR 输出，重新实际运行四片对齐、学习句分割和翻译；不是重跑 ASR。后三阶段分别约 350 / 145 / 589 秒。`audit_pipeline_integrity.py` 检查所有词和学习句，不仅检查截图位置：

| 音频 | 保留输入词 | 学习句 | 时间回退词（待审） | 英文回退译文 |
| --- | ---: | ---: | ---: | ---: |
| Switzerland | 1,768 | 159 | 30 | 5 |
| Rinjani | 3,936 | 355 | 16 | 6 |
| Bangladesh | 4,142 | 382 | 53 | 10 |
| AIRFLARE | 2,873 | 172 | 21 | 6 |

全部 12,719 个输入词无丢失、无重复、无文本改写；句内源词序倒置从上一轮 AIRFLARE 的 1 段降至 0；学习单元完整分配所有词，跨至少 4 秒词间隔的错误合句为 0。翻译保留学习句原文与词范围；1,068 条学习句中 1,017 条译文未审核、27 条英文回退、24 条确定性数字转换。**以上是结构完整性结果，不是听音准确率或翻译准确率。**

短句仍有不能靠回退修好的情况。例如 Bangladesh 的一处短句，末尾两词不再被 CTC 提前约 5 秒，但前几个词的原 ASR 时间本身已经错了。整句末尾和画面字幕相交后，粗 OCR 时间告警可能消失；不能据此宣称整句已对齐。全片精确短语审计只用于定位问题，仍需要独立发音边界参考。

## 独立模型复查全片缺口

新增 `run_independent_gap_probe.py`：从四部完整音频重新计算 VAD，检查最终词时间未覆盖的所有候选区间。超过 2 秒的词或明确估计词不能掩盖整段缺失声音；空字幕也不能被当成“无缺口”。片名、问题时刻和 OCR 台词不参与候选选择。

Parakeet 已对四片所有 98 / 288 / 361 / 105 个候选区间完成局部识别，保留全部原 token 和时间。随后让 Whisper 读取完全相同、经音频和对齐文件 SHA-256 验证的区间做对照。`cross_model_gap_consensus.py` 要求连续文字与时间相互支持，拒绝单词时间过长、现有词重叠、单独一词和低识别概率的候选；重复训练次数不能全局去重。

这条路线尚只输出候选和拒绝记录，不自动插入正式字幕。VAD 可能把环境声误判为语音，两种 ASR 也可能犯同样的错误；候选数量不是找回的正确词数量。

初轮还发现小块 VAD 会将一个漏句拆成多个过短缺口。因此 Whisper 缺口 r1 在 Switzerland 完成、Rinjani 部分执行后主动停止，未冒称四片完成；日志保留。r2 将候选扩展为最多 14 秒的完整词间空隙，另建目录。两种模型均实际完成四片的全部 89 / 265 / 298 / 100 个窗口（共 752 个），Whisper CUDA 约 1,465 秒，Parakeet CPU 约 396 秒。严格词序/时间对照分别留下 34 / 46 / 74 / 4 个待审词，**158 个待审词没有插入正式字幕**。

这也暴露了方案不足：Switzerland 约 04:22～04:28 的硬字幕可在画面直接看到，Parakeet 的完整缺口识别也找到了对应文本，但 Whisper 较长上下文仍漏掉它；短上下文则只能识别部分。两模型硬性一致会漏掉真实台词，不能作为唯一补全方法。此处经过画面抽查，不等于完成整片听音核验。

## 分句模型阈值与依存保护对照

核对本机 `wtpsplit` 的 SaT 实现，`-sm` 模型默认阈值为 0.25，而学习句实验此前使用 0.75。较高阈值会漏切无标点口语；另一方面，把所有跨边界的依存关系都当成禁止断句，也会将两个独立分句连起来。[SaT 官方说明](https://github.com/segment-any-text/wtpsplit) 推荐 `-sm` 用于通用断句，但默认阈值不保证对本项目自动达到 95%。

新增 `replay_learning_threshold.py` 保存每部完整音频的词/特征 SHA-256，先确认原配置能逐条重现 r5 学习句，再对同一批词和 SaT/spaCy 特征做参数对照；不重新识别、不重算模型概率，不冒称新的语音验证。初次两次脚本运行分别遇到调试文件省略外部哨兵、配置为冻结 dataclass 的格式问题，失败目录保留，修复后全片运行成功。

| 完整音频 | r5 学习句 / 超过 40 词 | 仅阈值 0.25 | 阈值 0.25 + 软依存保护 |
| --- | ---: | ---: | ---: |
| Switzerland | 159 / 7 | 176 / 3 | 181 / 2 |
| Rinjani | 355 / 12 | 379 / 9 | 382 / 8 |
| Bangladesh | 382 / 10 | 400 / 8 | 400 / 8 |
| AIRFLARE | 172 / 17 | 219 / 11 | 226 / 10 |

软依存策略仍保留实体、名词短语、主谓、动宾、助动词和固定组合的具体保护；仅允许语义模型越过较宽泛的依存弧。新增策略显式选择、默认关闭，没有按片名加入规则。四片输入词/句内顺序/学习范围均通过完整性检查；超过 40 词的单元 46→28 只是长句风险降低，不能当成句界准确率。

新增加的 7 个单词单元为 `right / okay / ups / start / ready / Hold / ready`，已检查相邻文本，不是简单把所有短句并回去；其语义正确性仍需独立听音参考。r7 的四片翻译已全部实际完成，另存于 `.validation/learning-threshold-r7-translation`，约 481 秒；所有输入原文、时间和词范围完整保留。

## 复现与验收

- `run_windowed_asr_experiment.py`：完整音频固定网格对照；保留全部原始窗口、窗口外上下文和异常词记录。
- `run_whisperx_asr_experiment.py`：实际 WhisperX ASR、CUDA `int8_float16`、batch 2，显存不足时不得并发启动另一个 GPU 模型。
- `compare_full_transcript_candidates.py`：比较完整输出与完整无 VAD 对照、未校对 OCR 候选，保留所有失败项。没有字幕的视频不编造参考。
- `run_parakeet_asr_experiment.py`：独立 Parakeet CPU/INT8 整片对照，保留原 token、时间、原识别文本；不喂入 OCR。
- `tools/utilities/download_caption_validation_assets.py`：固定版本依赖/模型下载和哈希检查；不安装到正式服务、不上传用户文件。
- `audit_pipeline_integrity.py`：全片源词身份、句内词序、学习句完整覆盖、长间隔合句与翻译输入守恒检查。
- `run_independent_gap_probe.py` / `cross_model_gap_consensus.py`：完整音频中所有待查缺口的独立模型诊断；不自动写入正式字幕。
- `replay_learning_threshold.py`：先验证原配置精确重现，再对全片缓存特征做阈值/依存策略对照。
- 完整音频队列串行执行；当前使用的原始服务和字幕缓存不变。

本文件是实验记录，不是发布说明。完整管线 r5、独立缺口 r2、r7 全片分句与翻译对照已结束；文字识别、语音时间、语义断句、中文翻译均未因此自动达到 95%。当前 207 项电脑端单元测试、Python 编译和 `git diff --check` 通过，但四个反复用于调试的视频不能同时充当未参与调参的验收集。仍需独立校对的完整参考及未参与调试的新视频，才能评估泛化准确率；没有打包、上传 GitHub 或宣称已经完成最终质量目标。
